## How to view

1. Open `index.html` in any modern browser
2. No internet connection required — fully self-contained
3. Share a view via URL fragment:
   `index.html#tab=trends&year=2035&scenario=climate_pressure`

## Tabs

| Tab | Contents |
|---|---|
| Overview | KPI cards + delta vs previous year + findings |
| Maps | BADC cartographic maps with coord grid |
| Multi-Year Grid | Side-by-side all years |
| Trends & Forecast | Chart.js + 3 scenarios + CI band |
| Reports | PDF / CSV / JSON downloads |
