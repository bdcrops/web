Age & Gender Guessing with Impression — How It Works

1. Best Frame Selector

Collect qualifying face/person observations per anonymous_person_id → score blur/resolution/occlusion/pose → retain best frame(s) → run expensive downstream once, not every frame. Per SESSIOnHANDOFF.md #11.

2. Demographics Estimation

FairFace/MiVOLO: gender Man/Woman → Male/Female 58/42 + confidence, age regression → buckets 18-24/25-34/35-44/45-54/60+ . Confidence/provenance kept, unknown allowed. Replace body-shape heuristics completely per SESSIOnHANDOFF.md #12.

3. Impression Link

Dwell accumulation per ID → if > threshold + viewing zone → is_verified_impression=true → attach demographics from best_frame. Aggregate: Reach 2,847 = all IDs, Impressions 1,921 = verified subset. Gender % from impressions, not raw detections.
