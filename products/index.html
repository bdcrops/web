Two Runtimes — Critical Distinction

Batch (existing executor.run_unit): GazeData, HighwayBillboard — kick off → artifacts → exit. Streaming (vision/runtime/daemon.py): Surveillance, Drone, TrafficControl — long-lived per-feed loop → reconnect on drop → emits events continuously. edge_sync.py for CTG hill terrain offline queue + sync.

Governance Mandatory

Same core powers DOOH billboard and defense feeds — privacy tier determines biometrics output, redaction auto-blurs faces unless authorized, audit log chain-of-custody, confidence labeling estimated end-to-end — legally mandatory before live CCTV goes into production per Plan1.md Phase 3.
